## Keyboard Shortcuts

| Tombol | Fungsi |
|---|---|
| `Space` | Start / pause |
| `R` | Reset |
| `F` | Selesai dan catat waktu |
| `1` / `2` / `3` | Pomodoro / Short Break / Long Break |
| `N` | Tambah tugas baru |
| `M` | Putar atau jeda video |
| `T` / `P` / `C` / `H` | Pindah ke Timer / Projects / Calendar / 10,000h |
| `Esc` | Tutup pop-up |
| `?` | Buka pengaturan timer (termasuk daftar pintasan) |
