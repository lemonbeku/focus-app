Pintasan keyboard

Hanya berfungsi saat kamu tidak sedang mengetik di kolom isian.

Tombol	Fungsi
Spasi	Start / pause
R	Reset
F	Selesai dan catat waktu
1 2 3	Pomodoro, Short break, Long break
N	Tambah tugas baru
M	Putar atau jeda video
T P C H	Pindah ke Timer, Projects, Calendar, 10,000h
Esc	Tutup pop-up
?	Buka pengaturan timer (ada daftar pintasan)
